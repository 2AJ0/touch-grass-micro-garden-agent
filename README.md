# 🌿 Local Micro-Garden & Frost Date Advisor Agent

An open-source AI agent built for the **Hacktoberfest Open-Source AI Challenge (Week 1)** centered around the **"Touch Grass"** theme.

## 🛠️ Tech Stack & Partners
- **Framework:** [Mastra](https://mastra.ai/) (`@mastra/core`)
- **LLM Engine:** Local open-source `llama3.1` via [Ollama](https://ollama.com/)
- **Validation:** [Zod](https://zod.dev/)
- **Runtime:** Node.js + TypeScript (`tsx`)
